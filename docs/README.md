## 本应用是什么

- **是**：官方 DeepSeek Harness Web UI 的桌面宿主（窗口 + 生命周期 + 网络相关设置）
- **不是**：另一套 Agent / IDE；也不会默认给网页开任意本机文件/Shell 权限

更细的行为以应用内壳设置（含「关于」分区）为准；本文随版本更新。
