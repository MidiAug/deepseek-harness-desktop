# 排查

> 状态：随真实错误文案补充；先列高优先级场景。

## 打不开 / 一直停在准备中

- 检查网络；公司网或需代理时，先到设置里配好再重试  
- 看向导或日志中的阶段提示（下载、校验、启动）  
- 杀软/管控软件是否拦截了 Node 或本机回环端口  

## 能开窗但页面空白

- 确认本机 `127.0.0.1` 上 harness 端口已监听（关于页或状态区若有端口号可对照）  
- 是否误开了旧实例占端口；关掉所有 deepseek-harness-desktop 后再开  

## 关掉应用后仍有 node / dsh

- 再开一次应用（启动清扫）或结束对应进程后重试  
- 若可稳定复现，记下壳版本与 harness 版本再反馈  

## 代理下插件安装失败

- 确认代理对 **应用本身** 生效，而不仅是浏览器  
- 镜像与代理都配时，确认失败步骤是「下载壳资源」还是「dsh plugin」
